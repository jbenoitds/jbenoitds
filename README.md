### Hi, I'm Jean-Benoit

I build tested, dependency-light tools for scientific and health data, in Python and C++.

I spent 12 years as a research data analyst in health and social science (REDCap, SPSS, qualitative coding, EMR indicators) and taught myself to program along the way. I'm now doing an MSc in computational physical chemistry at the Université de Montréal (NSERC), where I write research software every day.

Most of these projects started as tools I needed for my own work:

| Project | What it does | Started |
|---|---|---|
| [cpp-quantum-kernel](https://github.com/jbenoitds/cpp-quantum-kernel) | C++17 Hartree–Fock / MP2 library written from scratch, validated against PySCF | 2024 |
| [corpus-sentence-aligner](https://github.com/jbenoitds/corpus-sentence-aligner) | Aligns English/French documents sentence by sentence (C++17) | 2019 |
| [health-survey-pipeline](https://github.com/jbenoitds/health-survey-pipeline) | Cleans, validates and scores REDCap and survey exports from one YAML file | 2020 |
| [emr-access-indicators](https://github.com/jbenoitds/emr-access-indicators) | Primary-care access indicators from EMR extracts (C++17) | 2021 |
| [thermo-reaction-tool](https://github.com/jbenoitds/thermo-reaction-tool) | Reaction thermochemistry and equilibrium calculator | 2022 |
| [CFX-AD](https://github.com/jbenoitds/CFX-AD) | Code for our JCTC submission: an exchange–correlation functional with JAX autodiff | 2025 |

Most of them lived on my laptop for years, without version control, before I started publishing them in November 2026. That's why each repository starts with a single commit; its "Project history" section says when it was actually written, and where AI tools were used.
